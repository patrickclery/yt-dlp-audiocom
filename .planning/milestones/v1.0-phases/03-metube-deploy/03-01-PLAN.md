Header comment:
- purpose
- the script never runs sudo, and only prints the install command
- its only state changes are `docker restart metube` and, with `--smoke`, one new prefixed download
- usage
- env vars

Conventions copied from scripts/test-live.sh:
- Each step prints exactly one `ok: …` or `FAIL: …` line.
- Capture command output into a variable and grep the variable. Never pipe a command into a quiet grep (the Phase 2 D-13 SIGPIPE false-failure reason); explain this in a prose comment without writing the piped form.
- Guard every grep whose no-match is a legitimate outcome, and every `$(...)` that may fail, so `set -e` cannot abort a step.
- The last line is `DEPLOY OK` (exit 0) when no step failed, else `DEPLOY FAILED` (exit 1).
- Never print the raw yt-dlp output or the /history JSON, either of which could carry signed media URLs. On a failed load check, print only the `Extractor Plugins:` and `Plugin directories:` lines and any `Error while importing` lines.

Settings:
- SRC is the repo's yt_dlp_plugins/extractor/audiocom.py, as an absolute physical path derived from the script's own location (the parent of its directory, via `pwd -P`).
- DEST is `${AUDIOCOM_INSTALL_PATH:-/opt/metube/plugins/yt_dlp_plugins/extractor/audiocom.py}`.
- METUBE_URL defaults to http://127.0.0.1:8085 and METUBE_DOWNLOADS to /tank/docker/metube/downloads.
- The container name is metube and REF is the reference URL.
- First check that docker, curl, jq, ffprobe, cmp and sha256sum are on PATH: print `FAIL: missing tool <name>`, then DEPLOY FAILED, and exit 1.

Options: no option means deploy, and `--smoke video` adds the smoke step. Any other argument prints usage and exits 2.

Steps, in order:
1. Install check (per CONTEXT: Deploy mechanism). If DEST is missing, differs from SRC (`cmp -s`), or has a mode (`stat -c %a`) other than 644: print the matching FAIL line, then `Run this, then re-run scripts/deploy-metube.sh:`, then (via printf, not a heredoc) two spaces followed by `sudo install -m 644 <SRC> <DEST>`. Then print DEPLOY FAILED and exit 1. Nothing after this step runs, so a stale or half-written install never triggers a restart. On success print `ok: installed plugin matches repo (sha256 <first 12 hex of SRC>)`.
2. `find /opt/metube/plugins -name __init__.py` must print nothing. Then print `ok: no __init__.py under /opt/metube/plugins`. Otherwise print a FAIL naming the path and saying it shadows MeTube's bundled plugins, then DEPLOY FAILED, and exit 1 before any restart (PITFALLS 7).
3. `ok: rumble_fix.py present` when /opt/metube/plugins/yt_dlp_plugins/extractor/rumble_fix.py exists. A FAIL here does not stop the run.
4. Restart (CONTEXT: Restart).
   - Record `docker inspect -f '{{.Id}} {{.State.StartedAt}}' metube` and run `docker restart metube`, capturing its output.
